# 질문형 카페 글 + 댓글 티키타카 프롬프트

레퍼런스: `m.cafe.naver.com/pinkmzugh/49` (키워드 `집들이 선물`, 조회 614, 댓글 15)
네이버 통합검색 카페 탭에 노출된 글의 구조를 그대로 따른다.

## 핵심 전략

**본문에는 제품명을 절대 쓰지 않는다.** 본문은 순수한 질문글이고,
광고 제품은 **댓글에서 다른 사람이 추천해주는 형태**로만 등장한다.
검색으로 들어온 사람이 "실사용 후기 묻는 글"로 읽어야 한다.

## 1. 제목

형식: `{키워드} + 추천 부탁드려요! / 뭐가 좋을까요? / 다들 어떤 거 쓰세요? / 있나요?`

- 키워드를 제목 맨 앞에 그대로 넣는다
- 물음표 또는 느낌표로 끝낸다
- 20자 내외
- 광고 문구, 단정형 제목(`~하는 법`, `~총정리`, `~BEST 5`) 금지

예시
- `집들이 선물 추천 부탁드려요!`
- `냉장고 탈취제 뭐가 좋을까요?`
- `실내방향제 다들 어떤 거 쓰세요?`
- `신발 탈취제 냄새 잘 잡히는 제품 있나요?`

## 2. 본문

분량 5~7문단, 각 문단 1~2문장. **문단 사이에 반드시 빈 줄 한 줄.**

순서를 그대로 따른다.

1. **상황** — 왜 이걸 찾게 됐는지 구체적 상황 한 줄
   > 이번 주말에 친구 집들이 가기로 했는데 선물 고르는 게 생각보다 어렵네요.
2. **이미 고려한 선택지 + 그게 별로인 이유** — 뻔한 답을 미리 쳐낸다
   > 예전에는 디퓨저나 캔들 같은 걸 많이 했는데 향은 취향도 많이 타고 이미 받은 게 있을 수도 있어서 다른 걸 찾아보고 있습니다.
3. **제약 조건** — 가격, 취향, 상황상 애매한 지점
   > 신혼집이라 이것저것 새로 들였을 텐데 너무 부담스러운 건 또 애매하고, 그렇다고 너무 평범한 것도 성의 없어 보일 것 같더라고요.
4. **검색은 해봤다 + 실사용 후기가 궁금하다** — 여기서 제품 카테고리를 흘린다(브랜드명 아님)
   > 검색해 보니까 집들이 선물로 실용적인 생활용품이나 집 안 냄새 관리 제품도 많이 한다던데 실제로 받아보신 분들은 어떠셨나요?
5. **추천 요청 마무리** — 키워드 반복 + 장단점까지 물어본다
   > 받았을 때 만족했던 집들이 선물 있으시면 추천 부탁드립니다. 집들이 선물 고민 중이라 이것저것 보고 있는데 결정을 못 하겠네요ㅠㅠ 실사용 만족도 좋은 집들이 선물 있으면 장단점도 같이 알려주세요!

### 본문 규칙

- 키워드를 본문에 **4~5회 자연스럽게 반복**한다. 억지로 끼우지 않는다.
- 존댓말, 가벼운 구어체. `~네요`, `~더라고요`, `~같아요`
- 이모티콘은 `ㅠㅠ`, `ㅋㅋ` 정도만, 글 전체에서 1~2회
- 금지: 제품명/브랜드명, 링크, 가격 정보, 이미지, 목록(`-`, `1.`), 소제목, 정보성 설명
- 절대 전문가처럼 쓰지 않는다. 아는 게 없어서 묻는 사람이다.

## 3. 댓글 (티키타카)

**댓글 10~15개.** 다른 계정이 답을 주면 **작성자가 거의 매번 1줄로 받아친다.**

기본 리듬
```
[타계정] 의견/추천 한 줄
[작성자] 리액션 한 줄
```

레퍼런스 실제 흐름
| 타계정 | 작성자 |
|---|---|
| 와인도 많이 하는데 술 안 마시면 애매하더라고요 | 친구가 술을 안좋아하네요ㅠ |
| 집들이 선물은 가격보다 센스가 중요한 듯해요 | 센스가 너무 어렵네요ㅠㅠ |
| 저는 휴지나 세제 세트가 은근 제일 실용적이더라고요 | 맞아요ㅋㅋ 결국 소모품이 오래 기억나는 것 같아요 |
| 신혼부부면 식기나 커피잔 같은건 어떨까요? | (리액션) |

### 광고 제품 삽입 지점

전체 댓글 중 **1~2개에서만** 제품명을 언급한다. 위치는 중간(4~7번째).

```
[타계정] 아무래도 새집이면 새집 냄새가 많이 나니까 탈취제 선물 추천이요!
        {제품명} 선물 받았는데 정말 좋아서 꾸준히 쓰고 있어요ㅋㅋ
[작성자] 취향 안타는 제품일까요?
[타계정] (사용감/지속력/무향 여부 등 한두 줄로 자연스럽게 답)
```

핵심: 작성자가 **되물어서** 제품 설명이 한 번 더 나오게 만든다.

### 댓글 규칙

- 한 댓글 1~2문장. 길게 쓰지 않는다.
- 계정마다 말투를 다르게. 같은 어미 반복 금지.
- 제품명 언급 댓글도 **개인 경험**으로만 쓴다. 성분/스펙 나열 금지.
- 나머지 댓글은 제품과 무관한 일반적인 추천(휴지, 세제, 식기, 커피잔 등)으로 채워 광고 티를 지운다.
- 작성자 답글은 짧게. `맞아요ㅋㅋ`, `그것도 좋겠네요`, `~네요ㅠ` 수준.

## 4. 출력 형식

```
[제목]
(제목 한 줄)

[본문]
(문단 사이 빈 줄 포함한 본문)

[댓글]
1. (타계정) ...
2. (작성자) ...
3. (타계정) ...
...
```

## 5. 체크리스트

- [ ] 제목이 질문형이고 키워드로 시작하는가
- [ ] 본문에 제품명/브랜드명이 하나도 없는가
- [ ] 키워드가 본문에 4~5회 들어갔는가
- [ ] 문단 사이 빈 줄이 있는가
- [ ] 댓글에서 제품 언급이 1~2개뿐인가
- [ ] 작성자가 제품 댓글에 되물었는가
- [ ] 정보성 문체(설명체)가 섞이지 않았는가
